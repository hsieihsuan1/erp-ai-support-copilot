ERP Support Copilot

Local, synthetic support workflow. No LLM or live cloud integrations.

  1. Load extension/ unpacked in Chrome or Edge.
  2. Open the synthetic ERP screen and click the injected support button.
  3. Review and send the message; inspect cited runbooks.
  4. Review the transcript and explicitly create a mock ticket.

Without loading the extension, inspect the standalone widget. This fallback does not demonstrate extension injection.

Demo identities are public aliases, not secure authentication. Bind the server to loopback only.
